# baselines branding

The primary icon for the `baselines` crate is:

- `baselines-icon-midnight-hex-v2.png`: a pale-aqua signal and gently varying
  lime baseline inside a midnight hexagonal badge. This is the icon used by
  the project README and package documentation.

The remaining square bitmap concepts are retained as brand exploration:

- `baselines-icon-spectral.png`: orange spectral peaks separated from a smooth
  cream baseline.
- `baselines-icon-monogram.png`: a compact cyan lowercase-b shape built from a
  baseline curve and signal peaks. This has the clearest 64 px silhouette.
- `baselines-icon-surface.png`: a teal 2D surface above a coral reference
  curve; most descriptive of the crate's 2D support, but best at larger sizes.

The primary image is a 1254 by 1254 RGBA PNG with a transparent exterior. The
branding assets are excluded from the Cargo package so they do not increase
crate download size; crates.io displays the primary icon through the packaged
README.
